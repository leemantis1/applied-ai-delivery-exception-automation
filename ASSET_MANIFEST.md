# Asset Manifest

This package contains the Markdown, workflow, documentation, and screenshot assets for the Project 3 GitHub repository.

Repository: `applied-ai-delivery-exception-automation`
Project: **AI-Powered Last-Mile Delivery Exception Handling Automation**
Program: UT Austin Post Graduate Program in AI Agents for Business Applications

## Purpose

This repository is intended to support a public, portfolio-safe review of applied AI delivery thinking. It shows business problem framing, workflow architecture, n8n orchestration, tool-calling agents, RAG, deterministic escalation logic, critic validation, evaluation discipline, sanitization controls, and pilot-readiness planning.

It should not be positioned as a production-ready system, deep machine learning engineering project, or proprietary course-material release.

## Public Release QA Checklist

Before publishing or updating the repository, verify that the uploaded files do not include:

- API keys,
- credential IDs,
- active webhook URLs,
- private n8n instance URLs,
- local file paths,
- raw course-provided datasets,
- proprietary playbooks,
- SQLite database files,
- customer records,
- customer PII,
- private execution payloads,
- internal project notes that were not intended for public review.
